01. The Philosophy

I. The Drydock Standard

We treat every session as a refit. If we board a server, we leave it structurally sounder than we found it. Technical debt is rust; we do not paint over it. We grind it down and weld it shut.

II. Managed Mutation

The Code is the Captain. We never fix a server manually via SSH. Idempotency is Law. We do not burn down the ship to fix a leaking pipe; we use Ansible to apply precise, idempotent repairs.

III. Compartmentalization

A ship without bulkheads is a coffin. Isolation via KVM. Containment via Namespaces. Identity via Authentik. No one enters the engine room without SSO.

IV. Architecture First

We are the Architects; AI is the Workforce. We define the Intent and the Vibe. We review every line against the "Purist" standard. We do not commit what we do not understand.

V. Documentation is the Blueprint

If the README is outdated, the code is broken. If it's not in an ADR, it didn't happen. Documentation is the primary artifact.
